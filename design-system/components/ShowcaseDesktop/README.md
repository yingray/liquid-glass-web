# ShowcaseDesktop

ShowcaseDesktop is the 1440px app layout. At the top: nav islands grouped by scope — global (brand with the main destinations Studio / Library / Shows), project (project name, project tabs Picks / Sources with a pending count, and a glass "Export" next to them) and tools (search and queue, each with a tooltip, and the menu). On the left: the stage (one label at the top edge, notes marked with plates in the middle of the frame, and a grouped toolbar at the bottom edge: play and timecode as one group, a separate primary action, and Add Note and Share as another group), the contact sheet as an opaque content panel with tiles of one size, and the composer, which owns the ⌘K / Ctrl K shortcut. On the right: the inspector, with the selection first (Frame 14 and its notes), then the project (Needs Your Decision, Curator Question, Library, In Progress, All Notes, Activity).

Use it to check the hierarchy: backdrop blur appears only on the nav islands, the Export button and the stage controls, 8 in total; the inspector and composer are fixed on solid canvas and use the unblurred `lg-glass--flat`; the contact sheet, photos and thumbnails are content and are opaque. This is a review screen, so the only accent is the review action ("Review 4 Candidates"); Export stays glass, and Send stays neutral until there is text to send.

It is a showcase card at a fixed size, not a layout reference. For a layout that works from 320px to wide desktop, use AppShell.
