# Patterns

Patterns are the small parts that make up components: list rows, badges and status dots, callouts, inputs and chips, media frames, progress, pins, add tiles and waiting states. They all use opaque or `fill` styles and can go inside glass.

- **List row** `lg-row`: thumbnail (`lg-row__thumb`, 76 × 46; `--md` 68 × 40; `--sm` 48 × 30) + title (`label` role; two lines, then clamped) + subtitle (`caption`, `ink-muted`) + optional arrow (`ink-faint`). Hover uses `fill`; selected, current and pressed use `accent-soft`. Use the attribute that matches the meaning: `aria-selected` only on `role="option"` rows inside a `role="listbox"`; `aria-current="true"` for the item shown elsewhere (for example on the stage); `aria-pressed` for a toggle row. Wrap rows in `.lg-list`.
- **Select list**: rows people choose from go in `<div class="lg-list" role="listbox" aria-label="…" data-lg="list">` with `lg-row` children that have `role="option"`, `aria-selected` and `data-value`. `LiquidGlass.SelectList()` (bound by `init()`): with single selection, the selection follows focus; with `aria-multiselectable="true"`, arrows only move and Space toggles. `onChange(values, option)` reports the `data-value`s.
- **Badge** `lg-badge`: `--accent` (Recommended), `--ok` (Chosen), `--warn`, `--outline-warn` (Flagged), `--count` (monospaced numbers, neutral), `--mono` (scope, such as `@12–18`); `--sm` is used next to items and thumbnails. Counts in navigation and toolbars use the neutral `--count`; add `--warn` only for counts that need the user's attention. Labels on the stage use `lg-badge lg-glass lg-glass--media lg-glass--chip`, placed inside the top scrim band, one per stage.
- **Status dot** `lg-dot`: the dots differ in shape, not only in color: `--ok` filled circle (Chosen), `--accent` rounded square (Needs You), `--warn` diamond (Has Question), default hollow ring (Processing); `lg-legend` lays out a legend. Status is always a dot plus text, or a dot with an accessible name.
- **Callout** `lg-callout`: a suggestion on an `accent-soft` background (`--lg` for a larger title), or a question with `--warn`. A question always gives two concrete options: the first `inverse`, the second `tinted`.
- **Input** `lg-input` (46px minimum height, capsule) and `lg-textarea` (`radius-xl`), on `surface-inset` with a 1px `field-edge` boundary (≥ 3:1 before focus, WCAG 1.4.11). Field helpers: `.lg-field` (column), `.lg-field__label`, `.lg-field__help`, `.lg-field__error`. On error, set `aria-invalid="true"` and connect the help and error text with `aria-describedby` (help first). **Chip** `lg-chip`: inverted when on; 36px tall on touch devices.
- **Media frame** `lg-frame`: `radius-lg`, `stage` background. When selected (`aria-selected` in a listbox, `aria-current="true"`, `aria-pressed="true"` or `is-selected`), it draws a two-tone inset ring (the accent outside, a dark keyline inside, so it shows on any image) plus a check mark, in `::before` and `::after`. It is not an outline: the outline stays free for the focus ring. Numbers and labels on frames have no scrim band, so they use `lg-plate` (`media-plate` plate, no blur, ≥ 7:1 over a pure white frame). In a contact sheet, all tiles have one size: a contact sheet is not a timeline.
- **Plate** `lg-plate`: captions and numbers in the middle of the stage frame and on media frames. It is not glass: no backdrop blur, and it doesn't count toward the glass count.
- **Group headers**: `lg-panel__label` in panels, `lg-menu__label` in menus, `label-sm` + `ink-muted` in general layouts. Always normal case, never all caps.
- **Progress** `lg-progress` (3px; `--md` 4px), with `--lg-value` setting the width; inside a nav island, add `--neutral` (`ink` color, not accent). **Pin** `lg-pin` (teardrop shape, `--sm`, `--done`). **Add tile** `lg-add-tile` (dashed, turns accent on hover). **Waiting** `lg-spinner` (only on the stage).
